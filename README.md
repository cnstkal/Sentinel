# SENTINEL — 대한민국 센티넬관리청 포털

센티넬버스가 현실에 존재한다는 가정으로 제작한 **가상의 국가기관 웹사이트**입니다.

## 구성
- 국가 통합현황 / 실시간 관리 지표
- 기관소개 및 조직 체계
- 초상능력 관리의 역사·설립 연혁
- 센티넬·가이드 등록번호 조회
- 동조·가이드 지원
- 초상능력 관련 가상 법령·행정제도
- 센티넬관리청 보도자료
- 재난·긴급 대응 현황
- 국민 민원·안내 서비스

## 세계관 기본 설정
1987년 최초 공식 각성 사례가 확인된 이후 국가 차원의 능력관리 체계가 발전했으며, 2009년 기존 부처 업무를 통합한 센티넬관리청이 설립되었습니다. 2026년 현재 등록·보호·동조지원·재난대응을 담당하는 독립 국가기관으로 운영됩니다.

모든 법령명, 통계, 기관명, 사건 및 인물은 이 웹사이트의 가상 세계관을 위해 작성된 설정입니다.
